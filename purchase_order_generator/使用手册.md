# 采购单自动生成系统 — 使用手册

> 朗晨 PPY 品牌采购单批量生成工具（v1.5）
> 一句话：**填一个 Excel → 上传 → 自动生成全部采购单 + 领星导入文件**

---

## 1. 这个工具能做什么

运营算好每个 SKU（颜色×尺码）的采购数量后，上传输入文件，自动：

1. 按 **款号 × 工厂** 拆成多份采购单文件（每份 = 生产订单 + 每布行一张布料申购单）
2. 生成**领星批量导入采购单**（直接传给领星系统）
3. 生成**汇总明细表**核对
4. 全部打包成一个 zip 下载

---

## 2. 启动程序

```bash
cd purchase-order-generator
.venv\Scripts\python -m streamlit run app.py
```

浏览器打开：**http://127.0.0.1:8501**

## 3. 输入文件怎么填（重点）

输入文件 = **一个 .xlsx，含 3 个工作表**。用「PPY采购-输入模板.xlsx」复制改名即可（改名规则：`PPY采购-YYYYMMDD.xlsx`，**日期会被自动提取成订单号**）。

### Sheet1 主表（每行一个 SKU）

| 列 | 字段 | 怎么填 | 示例 |
|---|---|---|---|
| A | 款号 | 款号 | PPY4005 |
| B | SKU编码 | 唯一 | PPY4005-YH-2143 |
| C | SKU名称 | 含类型关键词（纯色/印花/混搭） | PPY4005-YH 亨利领睡衣套装 印花 |
| D | 颜色 | 色号+颜色名；**混搭色用 `+` 连接两段** | HX214 雪花红底 / #179 海军蓝+YH5126 棕蓝格子 |
| E | 尺码 | S~6XL（下拉选择） | L |
| F | 采购数 | 整数 | 10 |
| G | 工厂 | 加工工厂 | 嘉品 |
| H | 布行 | 单色填 1 个；**混搭色必填 2 个**（逗号/空格/分号分隔，即使同布行也写两个） | 剑邑布行 / 剑邑布行,宏裕布行 |
| I | 品名 | 面料名（一个款所有行相同） | 牛奶丝 |
| J | 备注 | 显示到订单 sheet 备注列 | 新颜色 |

**注意**：同一个款、同一个颜色的不同 SKU，**工厂和布行必须一致**（系统会校验，不一致报错——因为一般以颜色为最小单位下单，不一致多半是复制错误）。

### Sheet2 面料表（每个款一行）

| 列 | 字段 | 示例 |
|---|---|---|
| A | 款号 | PPY4005 |
| B | 产品名称 | 长袖亨利领睡衣套装 |
| C | 品名 | 牛奶丝 |
| D | 纸样名称 | PPY4005(2023.7.25) |
| E | 洗水唛成分 | 95% Rayon\n5% Spandex |
| F | 每条布出货数(件) | 40（布料条数 = 件数 ÷ 此数，向上取整） |
| G | 是否需要压缩袋 | 是/否 |
| H | 包装袋规格 | 29.5*37.5 |

### Sheet3 配置表（本次采购的固定项）

| 字段 | 说明 | 示例 |
|---|---|---|
| 品牌 | 订单品牌 | POPYOUNG |
| 账号代码 | 布料申购单备注列 | MLD-AM-US-PPY |
| 申请人 | 布料申购单申请人 | 肖体桥 |
| 联系地址 | 布料申购单办公室 | 东莞启创-朗晨 |
| **采购仓库** | **下拉选**（领星用，必须与领星系统一致） | 启创-立祥仓库B区 |

## 4. 生成结果说明

下载的 zip 包含：

| 文件 | 说明 |
|---|---|
| `PPY2026082701-PPY4005 长袖亨利领睡衣套装 纯色 印花 -嘉品.xlsx` | 生产订单（给工厂）+ 布料申购单（每布行一个 sheet） |
| `20260827_采购单汇总.xlsx` | 文件汇总 + 布行明细（核对用） |
| `20260827_领星批量导入采购单.xlsx` | **直接上传领星 ERP** |

**订单号规则**：`PPY` + 输入文件名日期 + 序号（序号按 款×工厂 组合顺序 01/02/03）。
**混搭色**：订单里一行显示；布料申购单拆两行（各归各布行，数量默认对半，生成前预览里可改）。

## 5. 常见问题

**Q：校验报错“同款同色出现多个工厂/布行”？**
→ 该颜色不同 SKU 的工厂或布行填得不一致，检查是否复制错误。

**Q：混搭色报“布行需 2 个”？**
→ 混搭色布行列必须填 2 个布行，用逗号/空格/分号分隔（如 `剑邑布行,宏裕布行`）。

**Q：生成的订单图片想换？**
→ 打开 `templates\thd_template_clean.xlsx` 右键图片→更改图片（**不要用“置于单元格”插入**）；或生成前在网页预览区下方上传 4 张图（仅当次生效）。

**Q：领星导入校验失败？**
→ 检查「采购仓库」是否与领星系统仓库名完全一致；供应商名（自动加了“工厂”后缀）是否在领星有对应供应商。

**Q：订单号不对？**
→ 订单号取输入**文件名里的 8 位日期**，确认文件名是 `PPY采购-YYYYMMDD.xlsx` 格式。
